# Five-day 32x32 coverage experiment

Target match: `fa3b2b52-b19d-4dd6-8280-41b001247940`. The user confirmed
`sample_32.json`; the preserved fixture is `tests/match_fa3b2b52_config.json`.
This is the 24-brand, five-day map, not the 27-brand, ten-day F2 tournament map.

The Quan solver now runs the existing daily-focused fleet repair, route repair
and next-day Supply preparation after the native large-map planner on
non-tournament 32x32 multiplayer configurations. It disables the native
two-day lookahead for that pass, matching the measured endurance policy.
Repairs use the remaining live deadline with 12-second and 8-second local caps;
the native baseline retains its original time allowance. Tournament profiles
and other map sizes retain their prior dispatch.

Offline comparison, fixed fleet `0000011`, dynamic own traffic, 57-second budget:

| Policy | Type | Daily | Serving |
|---|---:|---:|---:|
| Previous baseline | 24 | 116 | 152 |
| Unrestricted repair with native lookahead | 24 | 113 | 126 |
| Endpoint-preserving repair | 24 | 116 | 152 |
| One Supply | 24 | 109 | 135 |
| Endurance policy, selected | 24 | 119 | 161 |

Selected policy daily coverage: 23, 24, 24, 24, 24. Brand 17 remains missing on
day 1. Increasing repair budgets to 24/16 seconds did not solve that deficit
and regressed subsequent coverage; it is rejected. Full 120 Daily is not yet
achieved. These are offline results, not a submitted server match, and differ
from the diary reconstruction (117 Daily) because the planner and simulated
traffic/state trajectory differ. Do not treat them as server guarantees.

Reproduce from the repository root after building `tests/benchmark.cpp`:

```powershell
.\HexaUdon\.build\fa3b_final_benchmark.exe --sample .\HexaUdon\tests\match_fa3b2b52_config.json --types 0000011 --own-traffic --live-budget-ms 57000 --at-least 24 119 161
```

Formation selection was not changed or fully revalidated in this experiment;
the measured result uses the fleet in the historical diary. Opponent traffic
and different fleet selection require separate validation. Per-day details and
rejected experiments are in `checkpoints/2026-10-23-fa3b-search.json`.
